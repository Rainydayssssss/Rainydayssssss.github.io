Rain 的工具箱

任何电脑打开这个页面就能用。代码改动推送到 GitHub 后会自动构建发布，刷新页面或重新打开程序即是最新版。

国内直连 GitHub 很慢，页面或下载卡住时请打开代理软件（如 Clash）。Rain 工具箱会自动使用本机正在运行的代理下载程序。

网页应用

听书

导入 TXT、EPUB、Word、PDF 或直接粘贴文字，用微软“自然人声”或本机克隆的声音逐句朗读。连上云端后，电脑上生成好的整本音频在手机上直接播放。

电脑上请用 Microsoft Edge 打开；手机版见下方。 打开 →

诡秘档案

中文单人调查冒险：创建调查员、技能与 SAN 检定、多结局。首次打开后可离线游玩。

存档保存在当前浏览器里，可在应用内导出备份。 打开 →

听书连上云端同步后，书架、进度和生成好的音频在电脑和手机上都一样；诡秘档案的存档只保存在当前浏览器，换电脑或换浏览器不会自动同步。

手机

听书 · 安卓版

下载后在手机上点开安装（提示“未知来源”时选允许）。锁屏、切到后台都能继续听；以后有新版，打开听书会提示下载，直接覆盖安装。

下载安卓版（APK）

装好后点右上角“云端同步”→“扫码连接”，扫电脑上“云端同步”里的二维码，书和电脑上生成好的音频就同步过来了。

听书 · iPhone / iPad

用 Safari 打开 rainydayssssss.github.io/audiobook/，点底部的“分享”按钮，选“添加到主屏幕”。以后从主屏幕的“听书”图标打开：全屏、锁屏能继续播放，也能下载离线听。

苹果不允许不经 App Store 安装原生 App（需要每年 99 美元的开发者账号），所以 iPhone 用主屏幕网页应用，功能和安卓版一样。

Windows 桌面程序

推荐：Rain 工具箱（只需下载一次）

双击运行后会安装到本机并在桌面创建图标。以后点工具箱里的程序或桌面图标，会自动检查并使用最新版，不用再来这里下载。

下载 Rain 工具箱

第一次运行如果出现“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。需要 Windows 10 或 11。

影音转文字 本地视频/音频或 B 站、抖音链接转文字，导出 TXT、SRT、VTT。 zip · 版本
